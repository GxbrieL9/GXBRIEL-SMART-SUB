# 🚀 GXBRIEL SMART SUB

Интеллектуальный автоматический агрегатор и бенчмаркер VPN-подписок для **Karing**, работающий полностью бесплатно на **GitHub Actions**.

## 📌 Возможности

- **Поддержка протоколов**: VLESS, VMess, Trojan, Shadowsocks, Hysteria 2, TUIC.
- **Умная дедупликация**: фильтрация дубликатов серверов и повреждённых конфигураций.
- **Реальное тестирование**: liveness-проверка реальным соединением через ядро **Mihomo**.
- **Измерение скорости скачивания**: не просто ICMP/TCP-пинг, а реальный тест пропускной способности (speedtest).
- **Приоритет высокоскоростных узлов**: серверы со скоростью от **24 Мбит/с (3 МБ/с)** получают наивысший приоритет.
- **Топ-200**: автоматический отбор максимум 200 лучших доступных серверов.
- **Автоматическая публикация**: регулярное обновление Secret Gist без перезаписи при сетевых сбоях.
- **Совместимость с Karing**: генерация стандартного формата `subscription.txt` (Base64 V2Ray/Xray).
- **Автономная работа**: запуск по расписанию каждый час и вручную через GitHub Actions (`workflow_dispatch`).

## 📲 Подключение в Karing

Для подключения постоянной обновляемой подписки:

1. Скопируйте постоянную прямую ссылку на ваш Secret Gist:
   ```text
   https://gist.githubusercontent.com/GxbrieL9/33a47d59cdae1092917fcdb336b2b5ce/raw/subscription.txt
   ```
2. Откройте **Karing** → перейдите в **Профили (Profiles)** → **Новый профиль / Добавить подписку (Add Subscription)**.
3. Вставьте ссылку, задайте имя `GXBRIEL SMART SUB` и сохраните.
4. Включите автообновление подписки в настройках Karing (например, каждые несколько часов).

## ⚙️ Конфигурация GitHub Actions

### Секреты (Repository Secrets)
- `GIST_TOKEN` — GitHub Personal Access Token с областью `gist` для обновления Secret Gist.
- `SOURCE_URLS` — список исходных подписок с серверами.

### Переменные (Repository Variables)
- `GIST_ID` — идентификатор Secret Gist (`33a47d59cdae1092917fcdb336b2b5ce`).

## 🛡️ Безопасность и надёжность

- **Защита от сбоев**: если внешние источники недоступны или ни один узел не прошел проверку, рабочий список в Gist **не перезаписывается** пустым файлом.
- **Секреты не публикуются**: токены и приватные URL не выводятся в логи GitHub Actions.
- **Экономия ресурсов**: быстрый TCP/latency-префильтр отсекает мёртвые серверы до спидтеста, исключая избыточный расход трафика и лимитов GitHub Actions.
