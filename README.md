# GXBRIEL SMART SUB

Универсальная автоматическая мультиформатная подписка на базе [735754647/Free-Nodes](https://github.com/735754647/Free-Nodes).

**Проект полностью универсален и не привязан к какому-либо конкретному VPN-клиенту** (Karing, Hiddify, v2rayN, Mihomo / Clash Verge, sing-box и т.д.).

Каждый час GitHub Actions автоматически собирает узлы из доверенных источников (`SOURCE_URLS`), выполняет проверку доступности и единый тест реальной скорости скачивания через ядро Mihomo, отбирает до 200 лучших рабочих серверов (приоритет — скорость от 3 МБ/с / 24 Мбит/с) и публикует конфигурации одновременно в нескольких популярных форматах в Secret Gist.

---

## 🌐 Форматы экспорта и постоянные Raw-ссылки

Публикация выполняется в существующий Secret Gist через `GIST_TOKEN` и `GIST_ID`. Для каждого файла доступна **постоянная прямая ссылка (Raw)**, не привязанная к хешу конкретной ревизии или коммита:

| Формат | Файл в Gist | Совместимые клиенты | Постоянный URL (Latest Raw) |
| :--- | :--- | :--- | :--- |
| **V2Ray / Base64** | `subscription.txt` | Hiddify, Karing, v2rayN, Shadowrocket, Streisand, v2rayNG | `https://gist.githubusercontent.com/<OWNER>/<GIST_ID>/raw/subscription.txt` |
| **Mihomo / Clash** | `clash.yaml` | Mihomo Party, Clash Verge Rev, Clash Meta, Hiddify, Karing | `https://gist.githubusercontent.com/<OWNER>/<GIST_ID>/raw/clash.yaml` |
| **sing-box** | `singbox.json` | sing-box, Hiddify, Karing, Nekobox | `https://gist.githubusercontent.com/<OWNER>/<GIST_ID>/raw/singbox.json` |

> [!NOTE]
> Замените `<OWNER>` на ваш GitHub-логин (например, `GxbrieL9`), а `<GIST_ID>` — на ID вашего Secret Gist. При обращении по этим ссылкам GitHub всегда возвращает актуальную версию файла.

## 🚀 Особенности и архитектура

1. **Единый сборщик и бенчмарк**:
   - Автоматическая загрузка источников из репозитория (`config/sources.txt`) и из секрета `SOURCE_URLS`.
   - Дедупликация идентичных серверов по каноническим параметрам подключения.
   - Проверка TCP-доступности (TCP prefilter) для отсечения заведомо недоступных узлов.
   - Единый тест задержки (ping/RTT) и реальной скорости скачивания через ядро Mihomo.
2. **Фильтрация и приоритизация скорости**:
   - Минимальный желаемый порог скорости — **3 МБ/с (24 Мбит/с)**.
   - Сортировка: скоростные узлы (≥ 3 МБ/с) поднимаются на первые позиции по убыванию скорости, далее следуют остальные рабочие узлы по задержке.
   - Ограничение: до **200 лучших серверов**.
3. **Безопасная конвертация протоколов**:
   - Поддерживаются протоколы: VLESS (XTLS / Reality / TLS / WS / gRPC / HTTPUpgrade), VMess, Trojan, Shadowsocks, Hysteria 2, TUIC.
   - Если отдельный узел несовместим с синтаксисом одного из форматов, он исключается только из этого формата, не нарушая остальные.
4. **Отказоустойчивость и сохранение предыдущей версии**:
   - При сбое сети, пустом результате или ошибках сборки публикация в Gist не выполняется. Предыдущий рабочий список серверов в Gist остаётся неизменным.
5. **Полная автономность и бесплатность**:
   - Работает исключительно на бесплатных GitHub-hosted runners (`ubuntu-latest`) через GitHub Actions.
   - Не требует собственного VPS или внешнего сервера.

## 📲 Подключение в клиентах

### Hiddify
1. Откройте **Hiddify** → нажмите кнопку **+** (Добавить профиль).
2. Выберите **Добавить из буфера** или **Добавить по ссылке**.
3. Вставьте любую из постоянных ссылок (`subscription.txt`, `clash.yaml` или `singbox.json`). Hiddify распознаёт все три формата.
4. Включите автообновление подписки.

### Karing
1. Откройте **Karing** → перейдите в **Профили (Profiles)** → **+** (Добавить).
2. Вставьте постоянную ссылку `subscription.txt` (или `clash.yaml` / `singbox.json`).
3. Нажмите **Сохранить** и включите автообновление.

### v2rayN
1. Откройте **v2rayN** → перейдите в верхнее меню **Подписка (Subscription group)** → **Настройка групп подписки (Subscription setting)**.
2. Нажмите **Добавить (Add)**.
3. Вставьте ссылку на `subscription.txt` в поле **URL**.
4. Нажмите **Подтвердить** и обновите подписку (**Обновить подписку без прокси**).

### Mihomo Party / Clash Verge Rev
1. Откройте клиент → перейдите во вкладку **Подписки / Профили (Profiles)**.
2. Вставьте постоянную ссылку на `clash.yaml`.
3. Нажмите **Импорт (Import)** и выберите желаемый интервал автообновления.

### sing-box
1. Скопируйте постоянную ссылку на `singbox.json` или используйте его напрямую в конфигурации sing-box как профиль.
